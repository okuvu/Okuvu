# OKUVU — Simple Brand Kit

> One palette · matches the current website · purple family + honey + **soft sage complement** + pastels.
> Green stays but **soft/pastel only** — never bright/fluorescent.

## Contents
- `00-Logos/` — mark (light), mark (dark), app icons (SVG + PNG 512/1024). No lockups.
- `01-Palette/` — one palette sheet (PNG) + design tokens (CSS + JSON).
- `02-Guidelines/` — brand guidelines (logo, colour, type, voice).

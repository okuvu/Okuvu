## E9. The Postgres URL carries a placeholder, not a password

The story assumed a database password is exposed. It is not, and a gate that said
otherwise would be lying. Census of every `postgres(ql)://` URL in every commit reachable
from every ref, grouped by password shape (counts are this run's):

```
$ python3 - <<'PY'
import subprocess, re, collections
pat = r'postgres(?:ql)?://[^\s:/@"<>]+:[^\s@"<>]+@[^\s"<>]+'
commits = subprocess.run(['git','rev-list','--all'],capture_output=True,text=True).stdout.split()
out = subprocess.run(['git','grep','-P','-n','-I','-e',pat]+commits,capture_output=True,text=True).stdout
shapes = collections.Counter(); total = 0
for line in out.splitlines():
    for m in re.finditer(pat, line):
        url = m.group(0); total += 1
        try:
            cred = url.split('://',1)[1].split('@',1)[0]; _, pw = cred.split(':',1)
        except ValueError:
            continue
        shapes[pw[:6] + ('…' if len(pw) > 6 else '')] += 1
print('commits scanned:', len(commits), '| URL occurrences:', total)
for k, n in shapes.most_common():
    print(f'  password starts {k!r}: {n} occurrence(s)')
PY
commits scanned: 563 | URL occurrences: 2488
  password starts '[passw…': 1150 occurrence(s)
  password starts '${urle…': 364 occurrence(s)
  password starts ']+):([…': 364 occurrence(s)
  password starts '%s': 200 occurrence(s)
  password starts '${rand…': 156 occurrence(s)
  password starts '***': 155 occurrence(s)
  password starts '${q(s.…': 99 occurrence(s)
# exit 0
```

Every shape is a template (`${...}`), a mask (`***`), a printf placeholder (`%s`), a
[password] bracket, or a regex. No occurrence has a literal value. The scanner therefore
treats a placeholder password as "URL shape, not a credential" and counts it instead of
reporting it; `--verbose` prints the count, so the filter is visible rather than silent.

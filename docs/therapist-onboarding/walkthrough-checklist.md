## T-00: Sign in & orientation

- [ ] Therapist can sign in with their authorized account
- [ ] Therapist can identify the sidebar and its sections
- [ ] Therapist understands the "Patients" section shows their assigned clients

## T-01: Dashboard & caseload

- [ ] Therapist can see their full caseload
- [ ] Therapist can identify each column: Client, Care Plan, Status, Last Session, Safety
- [ ] Therapist can click a client to navigate to T-02
- [ ] Therapist understands what the Status badge means

## T-02: Client overview

- [ ] Therapist can find the care plan section
- [ ] **Discussed: what `provisional` vs `confirmed` assignment_state means**
- [ ] Therapist can explain the difference between provisional and confirmed
- [ ] **Discussed: what `reasoning_note` is and is NOT**
- [ ] Therapist understands reasoning_note is therapist-only (never shown to client)
- [ ] Therapist understands reasoning_note is informational, not prescriptive
- [ ] Therapist can find the safety state indicator
- [ ] Therapist can find the latest session summary

## T-03: Care plan assignment

- [ ] Therapist navigated to the care plan page
- [ ] Therapist saw the current plan and assignment state
- [ ] **Discussed: changing a plan sets assignment_state to confirmed**
- [ ] Therapist changed a care plan and observed the state transition
- [ ] Therapist read the notice about notes not being used by Evia

## T-05: Session notes

- [ ] Therapist navigated to the session notes page
- [ ] Therapist read the privacy notice
- [ ] **Discussed: T-05 notes are NEVER read by the AI**
- [ ] Therapist wrote and saved a sample note
- [ ] Therapist confirmed the note appears in the history
- [ ] Therapist understands the clinical boundary (therapist controls what informs AI)

## End-of-session navigation task

- [ ] Therapist navigated to a specific client's T-02 unaided
- [ ] Therapist correctly identified the assignment_state (provisional or confirmed)
- [ ] Therapist correctly explained what reasoning_note means
- [ ] Therapist correctly stated that session notes are NOT read by the AI

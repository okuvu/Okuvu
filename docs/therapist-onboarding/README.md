# Therapist Onboarding

This directory contains materials used for onboarding therapists onto the Evia
supervised beta (E13-S02).

## Contents

| File | Purpose |
|------|---------|
| `walkthrough-guide.md` | Guided walkthrough script for session facilitators |
| `reference-card.md` | 1-page reference card for therapists to keep |
| `walkthrough-checklist.md` | Per-session coverage checklist for facilitators |
| `session-notes-template.md` | Template for recording walkthrough observations |
| `beta-clearance-checklist.md` | Checklist for determining therapist readiness |
| `ux-issue-logging-template.md` | Template for surfacing UX issues to E13-S04 |
| `therapist-seed-guide.md` | How to add therapists to the allowlist |

## Before walkthroughs begin

1. Complete E13-S01 dogfooding and resolve any P0 portal issues
2. Seed all participating therapist emails via `seed-therapist.ts`
3. Verify each therapist can sign in with their authorized account
4. Review this guide and prepare screen-sharing setup

## Walkthrough flow (45-60 minutes per therapist)

| Step | Screen | Duration |
|------|--------|----------|
| 1 | T-00: Sign in & orientation | 5 min |
| 2 | T-01: Dashboard & caseload | 5 min |
| 3 | T-02: Client overview (key concepts) | 15 min |
| 4 | T-03: Care plan assignment | 10 min |
| 5 | T-05: Session notes & privacy | 10 min |
| 6 | Unaided navigation task | 5-10 min |

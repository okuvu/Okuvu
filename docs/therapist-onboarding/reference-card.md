# Evia Therapist Portal — Reference Card

## 1. Clinical Reasoning (`reasoning_note`)

| | |
|---|---|
| **What it is** | The system's internal inference about why a care plan was suggested during onboarding. Generated by the A2 agent. |
| **Where to find it** | T-02 Client Overview → "Clinical Reasoning" card |
| **Who can see it** | **Therapists only.** Never shown to the client. |
| **What to do with it** | Review it to understand the system's suggestion. Make your own clinical judgment. |
| **Is it a recommendation?** | No — it is informational transparency. The therapist makes the final decision. |

> **Remember:** reasoning_note is the system doing its homework and showing its work. You are not required to follow it.

## 2. Assignment State: Provisional vs Confirmed

| Aspect | Provisional | Confirmed |
|--------|-------------|-----------|
| **What it means** | System-suggested, not yet reviewed | Therapist-reviewed and set |
| **Who set it** | A2 agent (AI) | You (the therapist) |
| **Is it stable?** | May change as more data comes in | Stable until you change it |
| **Visual indicator** | Amber badge | Green badge |
| **Action needed** | Review and confirm if appropriate | None |

### How to confirm a provisional assignment
Navigate to T-03 (Program Evia) → open the care plan selector → save the same plan.
Saving any plan sets the state to `confirmed`.

> **Why this matters:** Confirming a care plan is a clinical decision. It signals that you have reviewed and approved the client's treatment track. A confirmed plan won't be auto-changed by the system.

## 3. Session Notes (T-05) — NOT Read by the AI

### Key rule
**Session notes are NEVER ingested, processed, or read by any Evia AI agent.**

### What notes ARE
- Your private clinical workspace
- Observations and reminders
- Anything you want to document during or after a session
- Stored securely in the database

### What notes are NOT
- NOT instructions to the AI
- NOT care plan configuration
- NOT shared with the client
- NOT used for training or improvement

### How to configure the AI instead
Use the **care plan selector** on T-03 (Program Evia). The care plan is how you tell the
Evia system what to focus on. Session notes are your private notes, period.

> **Architectural boundary:** The `therapist_notes` table is never queried by any agent
> pipeline. This is a deliberate, enforced design decision.

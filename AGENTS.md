# Agent Instructions — Evia

## Design Specifications

Before performing any frontend, UI, UX, Flutter, mobile, therapist portal, design system, accessibility, animation, or visual implementation work, you MUST first read the appropriate design document(s):

| Document | Location | Applies to |
|---|---|---|
| EVIA_Mobile_Design.md | `docs/design/EVIA_Mobile_Design.md` | Flutter mobile application |
| EVIA_Therapist_Portal_Design.md | `docs/design/EVIA_Therapist_Portal_Design.md` | Therapist Portal (Next.js) |

These documents define the authoritative design system, design tokens, typography, colors, spacing, motion, accessibility, reusable components, product voice, implementation constraints, and verified MVP scope.

Follow these specifications throughout implementation. If a request conflicts with them, raise the conflict — do not make assumptions.

These Design.md files are the single source of truth for design. This file references them rather than duplicating their contents.

All installed design skills should be used to enhance implementation quality while remaining faithful to the Design.md specifications.
